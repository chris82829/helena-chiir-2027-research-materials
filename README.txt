HELENA research materials

participants/: 347 persons, each with one subfolder and one TXT file per question.
condition/answer.txt contains A, B or C. MISSING represents an empty source cell.
There are 20 rating questions, two prior-experience questions and free-text feedback.
The 80 comments have been reviewed and identifying locations/details generalized.
No consolidated participant-level file or statistical results are included.

questionnaire/: German server wording, English translation, manuscript wording
and item-source mappings. Differences in wording are explicitly distinguished.
The posting-availability item's German original was not found on the server.

system/: anonymized system code and frontend, without database, job corpus,
responses, CVs, conversations, runtime files, model caches, credentials or analysis
scripts. The two advisory conditions use one shared base prompt; C adds its persona.
The system needs a locally supplied job corpus, model cache and configuration to run.
The server's exact historic study configuration is not certified by this package.
